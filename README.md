# Four Screen Rhythm Game — P0 Prototype

Godot 4で動く「4鍵・1画面・タップのみ」の最小プロトタイプです。ゲーム本体に加え、同じJSONを直接編集できる開発者用の軽量レベルエディタを含みます。4面切替、ホールド、ワイドノーツ、移動ノーツはまだ含みません。

## 必要環境と起動方法

- Godot 4.2以降（Standard版で可）
- プロジェクトマネージャーでこのフォルダーの `project.godot` を読み込み、`F5` または右上のプロジェクト実行ボタンで起動
- コマンドライン版がPATHにある場合は、このフォルダーで `godot --path .`（環境によっては `godot4 --path .`）

操作は `D F J K` の4鍵です。画面下部の判定線にノーツが重なった瞬間に、対応するキーを押してください。`R` で最初からリスタートできます。

## 開発者用レベルエディタ

ゲーム中に `F2` を押すとエディタへ移動し、もう一度 `F2` を押すとゲームへ戻ります。単独で軽く起動したい場合は次のコマンドでも開けます。

```powershell
godot --path . res://editor.tscn
```

エディタの主な機能：

- 既存JSON譜面の読込、上書き保存、別名保存
- 音源再生、停止、スクラブ、0.5〜1.5倍速プレビュー
- ノーツが下から上へ流れる縦型タイムライン、小節番号表示、自動追従
- ダブルクリックでノーツ追加、ドラッグで移動、右クリックまたはDeleteで削除
- BPM、1小節の拍数、第1小節の開始位置に基づく小節線
- 1/4、1/8、1/16、3連符、6連符のグリッドスナップ
- 「ステップ入力」モードで、曲を再生せずに `D F J K` を押してグリッド順にノーツを配置
- 「記録」モードで再生しながら `D F J K` を押してリアルタイム入力
- 「テスト」モードで実際の判定ロジックを使ったパーフェクト／グッド／ミス確認
- 選択ノーツの時刻・レーン直接編集、複製
- 元に戻す／やり直す（最大100段階）、未保存表示
- 重複ノーツ、範囲外時刻、レーン、音源不足などの検証

基本操作は、`Space` が再生／一時停止、`Ctrl+S` が保存、`Ctrl+Z` / `Ctrl+Y` が元に戻す／やり直すです。縦型タイムラインではホイールで時間方向へ移動し、`Ctrl+ホイール` で拡大縮小します。

「ステップ入力」モードでは、`D F J K` のいずれかを押すと現在のグリッドにノーツを配置して次のグリッドへ進みます。`Enter` はノーツを置かずに1グリッド進みます。同時押しを作る場合は、先に `Shift+D/F/J/K` で同じグリッドへノーツを追加し、最後のキーをShiftなしで押すか `Enter` で次へ進みます。

エディタからの保存は開発用の `res://` ファイルへ行うため、Godotエディターまたはソースプロジェクトから実行してください。エクスポート済みゲームでは書き込み用ツールとして使用しません。

## 楽曲の配置・差し替え

リポジトリには権利不明の音源を含めていません。そのため初期状態では無音の内部クロックで譜面が進み、音源なしでも判定を確認できます。

1. 利用権を確認済みのOGGファイルを `audio/prototype.ogg` として配置します。
2. Godotエディターにインポートさせてから実行します。
3. 別のファイル名を使う場合は `charts/test_chart.json` の `audio` を `res://` から始まるパスへ変更します。

MP3/WAVなどGodotが読み込める形式も使用できます。その場合もJSONのパスを実ファイルに合わせてください。`offset_sec` は譜面時計への補正秒数で、正にすると判定時刻が先へ進みます。

## 譜面の編集

`charts/test_chart.json` の `notes` を編集します。

```json
{ "type": "tap", "time": 2.5, "lane": 2 }
```

- `time`: 曲開始からの判定時刻（秒）
- `lane`: 左から `0, 1, 2, 3`（それぞれ `D, F, J, K`）
- `duration_sec`: プレイ終了時刻。最後のノーツより後に設定します。
- P0では `type` は `tap` のみです。無効なノーツは警告を出して読み飛ばします。

判定幅や描画速度などの仮値は `scripts/game_config.gd` に集約しています。

## 現在の判定仕様

- PERFECT: 判定時刻との差が55ms以内
- GOOD: 判定時刻との差が120ms以内
- MISS: GOOD幅を過ぎた未処理ノーツ
- PERFECT/GOODでコンボ加算、MISSでコンボを0へ戻す
- 空打ちはノーツを消費せず、コンボにも影響しません。
- 位置表示はフレーム加算ではなく、音声再生位置（音源なしでは単調時計）とノーツ時刻から毎フレーム再計算します。

## 現時点の制約

- 1画面・4レーン・タップノーツだけです。
- プレイヤー向けの音声・表示・判定オフセット設定UIはありません。開発用エディタでは譜面オフセットを編集できます。
- 得点、ポーズ、選曲、リザルト画面、キーコンフィグUIはありません。
- デフォルトキーは起動時にGodotのInputMapへ登録します。コード内で物理キー入力を直接判定していません。
- エディタで保存してゲームへ戻ると、譜面JSONを再読込します。
- 音声デバイスやOS環境ごとの遅延調整は今後の課題です。
